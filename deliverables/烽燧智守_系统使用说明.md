# 烽燧智守系统使用说明

## 快速开始

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

访问 `http://localhost:5173`。无飞书配置时自动进入模拟演示模式；生产预览使用 `npm run build` 后执行 `npm run preview -- --host 0.0.0.0`，访问 `http://localhost:4173`。

## 页面说明

1. 设备总览：查看统计、工艺拓扑、趋势、风险分布、最近预警与工单。
2. 设备台账：搜索、筛选、排序、编辑；进入详情或3D。
3. 设备详情：基础信息、健康度、工况、五类趋势、贡献度、历史记录。
4. 3D数字孪生：切换设备、模型资产、LOD和故障场景；旋转、缩放、节点点击、透明机壳和防护罩控制。
5. 预警中心：筛选、确认、误报、详情、关联工单与导出。
6. 辅助研判：意图问答、RAG证据、结构化诊断、MaintenanceAgent和图片辅助。
7. 维修工单：按轨道状态机接单、检修、待验证和完成。
8. 备件库存：查询、入库、出库、低库存和交易记录。
9. 运维知识库：检索故障现象、原因、检查步骤、处置方法和知识候选。
10. 六大能力映射：查看比赛能力到代码、Demo与交付物的对应关系。
11. 系统设置：查看分模块飞书/AI能力状态，测试连接、发送测试消息和重置演示数据。

## 标准演示闭环

设备总览→1号引风机→查看趋势→辅助研判/RAG/Agent→3D轴承温升→生成工单→已接单→检修中→填写记录与备件→待验证→输入维修后指标→已完成→健康度92→预警关闭→库存6→5→知识候选。

## 演示数据重置

进入“系统设置→比赛演示数据→重置演示数据”，按提示完成二次确认。重置只影响当前浏览器Mock数据，不删除飞书真实数据。

## 使用边界

页面所有遥测、健康度、风险和诊断默认是模拟演示。任何停机、拆检或安全操作必须由现场负责人结合企业规程决定。
