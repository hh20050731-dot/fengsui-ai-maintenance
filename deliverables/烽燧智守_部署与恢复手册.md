# 烽燧智守部署与恢复手册

## 前置条件

- Node.js 20及以上；npm 10及以上。
- 生产配置只写部署平台环境变量，不提交`.env`。
- GitHub默认分支与Vercel Production Branch保持`main`。

## 本地与普通Node

```powershell
npm ci
npm run build
$env:NODE_ENV='production'
npm run start -w @fengsui/server
```

## Vercel

- 根目录：仓库根目录。
- 安装：`npm ci`。
- 构建：`npm run build`。
- 输出：`apps/web/dist`。
- `/api/*`由Vercel Function处理，其他路径回退`index.html`。
- 先推功能分支观察Preview；全部验收后合并`main`触发Production。

## EdgeOne Pages备用演示

- 根目录：仓库根目录。
- 构建：`npm run build:edgeone`。
- 输出：`apps/web/dist`。
- 设置`VITE_OFFLINE_DEMO=true`，页面使用本地演示数据，不请求Vercel API。
- `edgeone.json`和`middleware.js`提供SPA回退。

## 发布门禁

```powershell
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npm run verify:production
git diff --check
```

任一失败不得发布。检查`/api/health`、`/api/integration/status`、`/digital-twin`、模型URL和无痕访问。

## 恢复与回滚

1. 在Vercel保留上一条Ready的Production Deployment。
2. 若新版本健康检查或主流程失败，优先在Vercel将上一条已验证部署重新指派为Production；该动作需要账号权限与人工确认。
3. Git端从失败提交的父提交创建修复分支，使用`git revert <失败提交>`生成可审计回滚提交；禁止`reset --hard`和force push。
4. 推送修复分支，经过Preview验证后再合并`main`。
5. 飞书数据不随前端回滚删除；先停止写入或切换模块能力，再核对多维表格记录。

## Mock恢复

系统设置中二次确认“重置演示数据”即可恢复固定初始状态。若页面缓存异常，可清理该站点localStorage；这不会删除飞书多维表格数据。
