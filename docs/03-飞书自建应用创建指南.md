# 03 飞书自建应用创建指南

以下操作需要应用管理员在飞书开放平台人工完成。

1. 登录[飞书开放平台](https://open.feishu.cn/)，创建“企业自建应用”，名称建议“烽燧智能运维”。
2. 在“添加应用能力”中开启“网页应用”和“机器人”。上传比赛用图标和应用说明。
3. 在“凭证与基础信息”获取 App ID、App Secret。App Secret 只写入服务器/Vercel Secret 环境变量。
4. 在“网页应用”填写桌面端和移动端主页，例如 `https://fengsui.example.com/`。
5. 在“安全设置”添加同一 HTTPS 域名为 H5 可信域名；添加完整主页为重定向 URL，建议保留结尾 `/`。
6. 根据 [权限清单](08-权限清单.md) 申请最小权限，提交管理员审核。
7. 创建测试版本、设置可用范围/测试人员；验证后再发布正式版本。比赛演示阶段不宣称生产发布。
8. 配置事件订阅 `https://你的域名/api/feishu/events`，先通过挑战校验，再订阅需要的卡片回调/消息事件。

后台界面和权限名称可能随平台升级变化。本文依据 2026-07 可访问的官方资料；提交前请在当前[官方文档](https://open.feishu.cn/document/)复核页面入口和权限名称。

## 本地联调

飞书后台通常要求公网 HTTPS。可使用经过组织允许的安全隧道把本地 5173/3001 暴露为同域 HTTPS；比赛正式演示建议直接部署测试环境，避免临时隧道不稳定。
