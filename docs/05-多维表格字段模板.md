# 05 多维表格字段模板

机器可读定义位于 `config/bitable-schema.json`。字段类型编码 `1` 为文本、`2` 为数字；数组和对象在适配层以 JSON 文本保存，便于跨表格版本稳定读取。

| 表 | 主键 | 主要字段 |
|---|---|---|
| Equipment | deviceId | deviceName、deviceType、systemArea、状态、工况、健康度、五类指标、负责人、时间 |
| Telemetry | recordKey | timestamp、deviceId、工况、振动、温度、电流、压力、转速、健康度、风险 |
| HealthSnapshots | snapshotId | deviceId、timestamp、healthScore、riskLevel、贡献度、模型版本 |
| Alerts | alertId | 设备、风险、异常指标、贡献度、原因、分析、建议、状态、关联工单、关闭时间 |
| WorkOrders | workOrderId | 来源预警、设备、负责人、期限、备件、处理记录、检查/维修/验证、前后健康度、状态、幂等键 |
| SpareParts | partId | 名称、分类、适用设备、现存/安全库存、单位、库位、供应商、库存状态、成本 |
| SparePartTransactions | transactionId | partId、出入库类型、数量、时间、操作人、关联工单、幂等键 |
| KnowledgeBase | knowledgeId | 设备类型、现象、指标、原因、检查、处理、工况、安全提醒、备件、来源 |
| OperationLogs | logId | 实体类型/ID、动作、操作人、详情、时间 |

## 字段约定

- 所有业务主键由应用生成，不使用记录 ID 充当业务 ID。
- 时间使用 ISO 8601 字符串，避免不同时区解析不一致。
- `indicatorContributions`、备件列表、处理时间线等结构化值使用 JSON 文本。
- 实际生产可把风险/状态改为单选、负责人改为人员、时间改为日期、设备关联改为关联记录；改造前须同步更新字段映射并做迁移验证。
- 不要删除脚本未识别的字段；初始化脚本只增不减。
