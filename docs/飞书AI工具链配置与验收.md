# 飞书 AI 工具链配置与验收

## 能力边界

- 飞书多维表格工单创建与状态同步：代码已实现，只有配置完整时使用真实模式。
- 飞书机器人与长连接：保留现有 Webhook 与 WebSocket 接入，回复复用同一意图路由。
- Aily、妙搭：代码接口与配置契约已准备，后台创建和发布需人工账号操作。
- 多维表格自动化：下表为安全配置方案，不宣称后台已自动创建。

## 自动化方案

| 触发 | 条件 | 动作 | 幂等键 |
|---|---|---|---|
| 新工单 | 风险为预警/严重 | 机器人发送工单卡片 | 工单编号 + 动作类型 |
| 严重预警 | alertStatus=待确认 | 通知运维群 | 预警编号 + 通知版本 |
| 超期提醒 | 高风险30分钟未接单或距截止不足4小时 | 督办卡片 | 工单编号 + 时间窗口 |
| 低库存 | currentStock≤safeStock | 库存提醒 | 备件编号 + 库存版本 |
| 工单完成 | 首次变为已完成 | 形成知识候选 | 工单编号 |

现有受保护任务接口：

- `POST /api/jobs/work-order-reminders`
- `POST /api/jobs/daily-operations-brief`

两者必须使用服务端 `CRON_SECRET` 验证，日志不得包含密钥。

## 验收

1. `/api/integration/status` 应按模块返回能力状态，未配置模块单独降级。
2. 工单模块配置完整时 `capabilities.workOrders.mode=feishu`。
3. 新建高风险工单写入成功后再发送通知；通知失败不得回滚工单。
4. 卡片接单必须走现有状态机，重复事件不重复推进。
5. 机器人七类问法返回不同数据驱动答案。
6. 回调挑战、Verification Token、Encrypt Key、事件幂等和日志脱敏按现有测试验证。
