# 离线演示保障与外部资源清单

## 结论

前端运行资源已全部随构建产物发布。执行 `npm run build:edgeone`（或普通构建时设置 `VITE_OFFLINE_DEMO=true`）后，不依赖 Vercel、飞书、第三方 CDN、在线字体、在线图片或在线 HDR；设备总览、台账、预警、3D 数字孪生、趋势图、辅助研判、工单、库存、知识库和设置页均使用浏览器本地模拟仓库。

本模式只用于比赛演示。真实飞书模式仍由 Node 服务端调用飞书 OpenAPI 和多维表格，不使用浏览器 `localStorage` 作为正式数据源。

## 外部资源清单

## 已本地化资源

- 3D 模型：`apps/web/public/models/induced-draft-fan.glb`，构建后为 `apps/web/dist/models/induced-draft-fan.glb`。
- 3D 环境：使用 Three.js 本地光源、材质和场景配置，不加载在线 HDR/环境贴图。
- 图标：`lucide-react` 作为 npm 依赖打包进前端 JavaScript，不通过图标 CDN 加载。
- 图表：Recharts 打包进本地构建产物。
- 字体：使用 Windows/macOS/系统中文字体栈，不声明 Web Font URL。
- 页面脚本和样式：全部位于 `apps/web/dist/assets`。

当前 GLB 约 18.1 MiB，低于 EdgeOne Makers 官方排障文档列出的 25 MiB 单文件限制。

## 离线构建与启动

依赖已安装后，在有线或无线局域网断开外网的情况下仍可执行构建和预览。EdgeOne 构建命令本身会启用离线演示：

```powershell
npm run build:edgeone
npm run preview -- --host 0.0.0.0
```

- 本机：`http://localhost:4173`
- 局域网：`http://<演示电脑IPv4地址>:4173`
- 查询 IPv4：`Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' }`

如局域网设备不能连接，只在 Windows 防火墙中允许 Node.js 的“专用网络”入站访问，不要关闭全部防火墙。

## 降级和数据保存

统一 API 层有两种进入本地演示的方式：

1. `npm run build:edgeone` 或 `VITE_OFFLINE_DEMO=true`：从首次渲染起直接使用本地模拟仓库，不发出后端请求。
2. 未强制离线：后端网络失败、超时或静态站 `/api` 返回非 JSON 时，自动切换到本地模拟仓库。

切换后页面顶部和系统设置显示“离线演示模式”，机器人操作只生成本地卡片预览。工单状态、维修记录、设备健康度、风险、预警、备件库存、交易记录和知识库候选保存在 `localStorage`。系统设置中的“重置演示数据”仍需二次确认，并恢复固定初始数据。

飞书真实接口没有被删除或改写。`VITE_OFFLINE_DEMO=false` 且 Node 服务可用时仍按现有 Mock/Feishu Repository 工作；Feishu 数据模式的多维表格和机器人依然需要网络。

## 断网演示检查表

- 首页：统计、趋势和列表可见。
- 设备监测：设备列表、详情及 24 小时/7 天/30 天趋势可见。
- 故障预警：列表、详情、确认和本地消息卡片预览可用。
- 3D 数字孪生：本地 GLB 加载，正常、叶轮不平衡、轴承温升、联轴器不对中四种状态可切换。
- 趋势图：随数字孪生故障场景切换。
- 模拟工单：可从 3D 或预警生成并进入本地工单状态机。
- 完整闭环：完成后健康度 68→92、预警关闭、风机轴承 6→5、生成知识候选；刷新后保留。
- 路由刷新：本地 Vite preview 自动回退；EdgeOne 使用根目录 `middleware.js` 将 HTML 导航改写到 `/index.html`。
