# 性能与兼容性报告

## Web 构建

Vite 生产构建通过，前端 source map 已关闭，避免生产源码映射暴露并减少部署产物。

| 主要产物             |    原始大小 |      gzip |
| -------------------- | ----------: | --------: |
| `DigitalTwinPage` JS | 1,048.40 KB | 288.45 KB |
| 主应用 JS            |   480.00 KB | 145.59 KB |
| 图表 JS              |   421.18 KB | 119.61 KB |
| 主样式               |    67.62 KB |  12.59 KB |
| React chunk          |    41.80 KB |  14.98 KB |

3D工作台按路由动态加载，因此大体积 Three.js/R3F 代码不会阻塞普通业务页面首屏。构建仍提示 3D chunk 超过 500 KB，这是可接受的已知优化项，后续可继续拆分控制组件和模型工具库。

## 3D资源

- 引风机 LOD0/1/2：约 7.03 MB / 1.73 MB / 0.49 MB。
- 八类通用设备每档 GLB 均小于 0.81 MB。
- 所有模型、图片、字体回退和场景灯光均为本地资源，不依赖在线 HDR/CDN。
- 默认增强模型提供原模型回退；LOD切换和资源释放已有自动测试。
