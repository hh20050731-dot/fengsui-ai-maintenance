# 06 多维表格初始化指南

## 准备

1. 新建多维表格，复制 URL 中的 App Token 到 `FEISHU_BITABLE_APP_TOKEN`。
2. 把企业自建应用添加为多维表格可管理协作者，确保应用具备表/字段/记录操作权限。
3. 配置 App ID、App Secret，保持 `DRY_RUN=true`。

## 初始化缺失表和字段

```bash
npm run bootstrap:bitable
```

DRY_RUN 只列出差异。确认目标 App Token 后：

```bash
$env:DRY_RUN="false"
npm run bootstrap:bitable
```

把输出的九张表 `table_id` 写入 `.env` 对应变量。脚本按表名和字段名幂等检查，不重复创建，不删除表/字段/记录。

## 写入比赛演示数据

先恢复 `DRY_RUN=true` 执行 `npm run seed:bitable` 查看计划，再设置 false。种子脚本按业务主键跳过已有记录，不覆盖已有内容。Telemetry 每台设备只写最近 8 个样例点，避免比赛初始化产生大量记录。

## 权限或接口失败

- 403/无数据：检查应用是否为该多维表格协作者，以及高级权限/数据范围。
- 权限码错误：在应用后台申请 `bitable:app` 或当前官方文档列出的等价最小权限并完成审核。
- 表 ID 错误：从对应数据表 URL 重新复制，不要把 App Token 当 Table ID。
- 自动创建表/字段受限：按 [字段模板](05-多维表格字段模板.md) 人工创建，再运行 DRY_RUN 校验。脚本不会伪造成功。
