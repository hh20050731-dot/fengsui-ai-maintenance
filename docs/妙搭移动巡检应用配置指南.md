# 烽燧智守妙搭移动巡检应用配置指南

> 当前状态：网站 API 与字段契约已具备；妙搭应用创建、企业授权与发布必须由账号管理员人工完成。移动端数据仍需标注比赛演示边界。

## 1. 页面

1. **巡检任务**：设备、计划时间、负责人、状态。
2. **提交巡检**：设备选择、巡检项、现场拍照、异常描述、风险等级。
3. **工单跟踪**：工单编号、设备、状态、负责人、截止时间。
4. **设备状态**：健康度、风险、工况、最近更新时间。

## 2. 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| deviceId | 单行文本/关联记录 | 是 | 稳定设备编号 |
| inspectionItems | 多选 | 是 | 振动、温度、泄漏、压力、噪声等 |
| photo | 附件 | 否 | JPG/PNG/WebP，建议不超过8MB |
| description | 多行文本 | 是 | 现场异常描述 |
| riskLevel | 单选 | 是 | 正常、关注、预警、严重 |
| reporterUserId | 人员 | 是 | 飞书用户身份 |
| submittedAt | 日期时间 | 是 | 毫秒时间戳或平台日期类型 |
| alertId | 单行文本 | 否 | 形成预警后回写 |
| workOrderNo | 单行文本 | 否 | 形成工单后回写 |

## 3. 动作与接口

- 设备列表：`GET /api/equipment`
- 多模态辅助研判：`POST /api/multimodal/inspect`
- 预警查看：`GET /api/alerts`
- 工单状态：`GET /api/work-orders/:id`
- 工单状态变更只能调用现有 `POST /api/work-orders/:id/transition`，不得直接改表格状态。

多模态接口只接收允许的图片类型和大小；结果必须显示“图像分析仅用于辅助研判，不能替代现场检测和专业人员判断”。

## 4. 自动化建议

1. 提交“预警/严重”巡检时通知值班负责人。
2. 关联现有活动预警，避免重复生成。
3. 创建工单前弹出二次确认并使用幂等键。
4. 工单完成后只读展示维修结果和知识候选状态。

## 5. 权限与验证

- 仅申请读取设备、提交巡检附件、查询本人或授权范围工单所需的最小权限。
- 权限名称和应用发布入口请根据当前飞书/妙搭官方后台确认，不在代码中猜测。
- 验证路径：选择1号引风机 → 拍摄演示图片 → 提交异常 → 查看结构化研判 → 人工确认后创建工单 → 妙搭显示最新状态。
