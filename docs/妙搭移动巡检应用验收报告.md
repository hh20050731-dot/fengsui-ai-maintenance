## 阻断原因与错误记录

1. 妙搭 Preview 服务端调用 `https://fengsui-ai-maintenance.vercel.app/api` 时超时，网关返回 HTTP 502；发布日志中的一次请求耗时约 8049 ms。
2. 现有生产域名的 `GET /api/inspections` 返回 404，说明新增巡检 API 尚未进入生产部署。
3. 功能分支的 Vercel Preview 部署已就绪，但受 Vercel Authentication 保护，API 请求返回 302 到登录页；没有把绕过凭据或任何 Secret 放进妙搭。
4. 当前网络解析/连通性检查表明妙搭所在网络无法稳定直连 Vercel 域名。这是运行环境到上游服务的可达性问题，不是五个 SPA 路由缺失。
5. 浏览器页面控制台未捕获到应用自身 JavaScript 异常；应用可见错误是上游 API 502。检查工具另有一次与应用无关的 Statsig 遥测超时。
6. 飞书客户端本身未显示应用业务错误，而是拉起外部 Chrome 完成授权与访问。授权完成后窗口标题正确；后续自动检查因工具无法确认 URL 而安全停止。
