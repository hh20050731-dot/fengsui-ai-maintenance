## 测试覆盖

- 创建巡检、Repository 持久化和重复提交幂等。
- 正常巡检不推荐预警；异常巡检可生成预警；同一巡检不重复生成预警。
- 从巡检创建工单；同一巡检不重复创建；工单带 `inspectionId` 和 `alertId`。
- 配置巡检表时真实调用 Base Repository；写入失败回退本地 Repository 并标记失败状态。
- 未配置通知群时工单成功；配置后发送交互卡片；工单状态变化刷新原卡片。
- 图片引用拒绝 Base64；多模态接口沿用图片类型和大小校验。
- API 失败由移动端显示明确错误，不显示伪造成功。
- 原有主系统测试全部继续通过。
