# 04 飞书网页应用免登配置

## 已实现流程

1. `apps/web/src/feishu/adapter.ts` 检测 `window.tt` / `window.h5sdk` 与飞书 UA。
2. 在 SDK ready 后优先调用当前推荐的 `tt.requestAccess({ scopeList: [], appID })`。
3. 旧客户端或旧 SDK 回退 `tt.requestAuthCode({ appId })`。
4. 前端只把一次性临时 code 发送到 `POST /api/auth/feishu/login`。
5. 服务端换取用户凭证并调用用户信息接口，建立 HttpOnly、SameSite=Lax 的应用会话。
6. 页面使用飞书姓名/头像/用户 ID 记录确认人、负责人和操作人；普通浏览器返回演示用户。

官方参考：[requestAccess](https://open.feishu.cn/document/web-app/gadget-api/open-ability/login/requestaccess?lang=zh-CN)、[免登流程](https://open.feishu.cn/document/client-docs/h5/development-guide/step-3?lang=zh-CN)、[获取用户信息](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/authen-v1/user_info/get)。

## 后台配置

- 网页应用主页必须与部署地址一致。
- 重定向 URL 写完整地址并建议以 `/` 结尾。
- H5 可信域名写 `https://域名`，不要包含未经允许的临时域名。
- `VITE_FEISHU_APP_ID` 可进入前端；App Secret 不可。

## 会话安全说明

比赛原型使用进程内会话。生产化应改用集中式会话存储或签名短会话，增加 CSRF 防护、权限角色映射、退出/撤销和会话审计。用户 access token 不返回浏览器，也不写日志。

## 兼容性

网页引入官方 H5 JSSDK `1.5.34` 的当前可用 CDN。发布前请依据官方“网页应用概述—开放接口”复核最新版本；升级只修改 `apps/web/index.html`，业务组件无需变化。
