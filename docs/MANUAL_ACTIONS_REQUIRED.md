# 必须由用户完成的人工操作

本清单不记录任何 Secret、Token、Key、验证码或账号信息。所有未完成平台操作均有 Mock 或规则降级，不影响本地比赛演示。

## 1. 豆包大模型 API 凭证

- 平台：火山引擎 / 豆包大模型控制台。
- 点击路径：模型服务控制台 → API Key / 推理接入点。
- 要做什么：创建比赛专用服务端凭证和模型接入点，并填写服务端环境变量。
- 变量名称：`DOUBAO_API_KEY`、`DOUBAO_MODEL`、`DOUBAO_BASE_URL`。
- 为什么必须人工操作：涉及账号、付费资源和密钥创建。
- 验证方式：系统设置中的 AI Provider 状态为可用，诊断响应 provider 显示 Doubao，日志不包含凭证明文。
- 安全降级：凭证缺失时自动使用 RuleBasedFallbackProvider。
- 是否影响正式网站：不影响基础闭环；只影响真实远程大模型调用。

## 2. 飞书 Aily 智能伙伴

- 平台：飞书 Aily 管理后台。
- 点击路径：飞书管理后台 / Aily → 创建智能伙伴 → 知识与工具。
- 要做什么：按 `docs/Aily配置指南.md` 绑定知识、配置查询工具并发布到指定范围。
- 变量名称：不在网站前端保存 Aily 密钥；如平台要求凭证，仅填写在对应安全后台。
- 为什么必须人工操作：需要企业管理员登录、应用范围审批和发布确认。
- 验证方式：使用指南中的六类示例问法，核对返回数据与网站一致。
- 安全降级：网站和飞书机器人继续使用本项目 IntentRouter/RAG/规则 Provider。
- 是否影响正式网站：不影响。

## 3. 飞书妙搭移动巡检应用

- 平台：飞书妙搭。
- 点击路径：妙搭工作台 → 新建应用 → 数据与页面 → 发布。
- 要做什么：按 `docs/妙搭移动巡检应用配置指南.md` 创建移动巡检表单、工单列表和 API 动作。
- 变量名称：按指南使用已有服务端公开 API 地址，不在妙搭页面保存 App Secret。
- 为什么必须人工操作：需要企业账号、页面发布和权限范围确认。
- 验证方式：提交一条标注为演示的巡检记录，确认网站预警或工单链路收到合法数据。
- 安全降级：网站内多模态巡检入口和 Mock 数据可独立演示。
- 是否影响正式网站：不影响。

## 4. 开启机器人能力并发布应用版本

- 平台：飞书开放平台。
- 点击路径：企业自建应用“烽燧智守” → 添加应用能力 → 机器人；随后进入版本管理与发布。
- 权限/能力：启用机器人能力；发布前按本清单确认最小权限。权限名称请以当前飞书后台显示为准。
- 环境变量：无新增密钥；应用凭证仍只配置在服务端 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`。
- 验证方式：应用详情显示机器人已启用，测试租户内能搜索并添加该机器人。
- 当前降级：网站、Mock 卡片预览和本地规则研判继续可用。
- 是否影响网站：不影响网页；未发布时机器人无法在真实会话工作。

## 5. 多维表格权限与协作者

- 平台：飞书开放平台 + 飞书多维表格。
- 点击路径：应用 → 权限管理；多维表格 → 协作者/高级权限。
- 权限名称：工单查重/读取 `base:record:read`，创建 `base:record:create`，更新 `base:record:update`；也可按企业策略使用 `bitable:app`。请在提交审批前按当前官方文档复核名称。
- 环境变量：`FEISHU_BITABLE_APP_TOKEN`、`FEISHU_WORK_ORDER_TABLE_ID`；其他业务表仅在启用对应模块时配置。
- 验证方式：系统设置中“工单多维表格”为可用；创建测试工单后表内出现唯一“工单编号”，状态推进后同一 record 更新而非新增。
- 当前降级：远端失败时本地工单保留并标记同步失败，可点击重新同步；其他未配置表保持 Mock。
- 是否影响网站：不影响页面打开；影响飞书工单真实持久化。

## 6. 消息发送、机器人入群和通知群

- 平台：飞书开放平台 + 飞书客户端目标运维群。
- 点击路径：应用 → 权限管理；群设置 → 群机器人/添加机器人。
- 权限名称：`im:message` 或 `im:message:send_as_bot`；更新原卡片还需当前后台所列消息更新权限（接口方案参考 `im:message:update`，请按官方文档确认）。
- 环境变量：工单群 `FEISHU_NOTIFICATION_CHAT_ID`；库存群可选 `FEISHU_STOCK_NOTIFICATION_CHAT_ID`。
- 验证方式：发送测试卡片，系统设置显示通知群可用，真实群收到一张卡片且状态推进后原卡片更新。
- 当前降级：群 ID 缺失或发送失败不回滚工单，只记录安全失败状态。
- 是否影响网站：不影响工单创建和网页闭环；只影响群通知。

## 7. 消息事件与卡片交互

- 平台：飞书开放平台。
- 点击路径：应用 → 事件与回调 → 事件订阅；卡片回调按后台当前入口配置。
- 权限/事件：`im.message.receive_v1`；私聊可申请 `im:message.p2p_msg:readonly`，群聊@机器人可申请 `im:message.group_at_msg:readonly`。卡片使用新版 `card.action.trigger`，不使用旧版 `_v1`。
- 环境变量：Webhook 使用 `FEISHU_VERIFICATION_TOKEN`、可选 `FEISHU_ENCRYPT_KEY`；本地长连接仍使用服务端应用凭证。
- 验证方式：向机器人发送“查询1号引风机状态”；依次点击工单卡片动作，确认网站、表格和原卡片一致。不得把回调里的临时 token 记录到日志。
- 当前降级：Webhook 不通时比赛演示可运行 `npm run feishu:ws` 使用官方长连接；网站独立可用。
- 是否影响网站：不影响普通 API；影响机器人查询和卡片按钮。

### 7.1 本次交互式工单卡片真实验收

以下步骤必须由已登录飞书测试租户的用户完成，代码和自动化测试无法代替真实群点击：

1. 部署完成后，如果比赛演示使用本地长连接，先按 `Ctrl+C` 停止旧进程，再重新运行 `npm run feishu:ws`，直到出现 `[Feishu WS] ready`。
2. 在已加入机器人的运维群发送：`@烽燧智守 查询1号引风机状态`。
3. 预期收到 JSON 2.0 设备研判卡片，而不是普通文本；卡片应显示健康度、风险等级、振动、温度、趋势证据和“生成维修工单”按钮。
4. 点击“生成维修工单”，确认多维表格只新增一条相同“工单编号”的记录，原卡片更新为待接单工单卡片。
5. 依次点击“确认接单”“开始处理”“提交验收”“验收通过”，每一步都核对同一多维表格记录的“工单状态”和原卡片状态同步变化。
6. 重复点击旧按钮时，预期提示状态已更新或未重复执行，不得重复推进、重复扣库存或重复生成知识候选。
7. 如果状态已写入多维表格但卡片未刷新，先重新查询工单确认业务结果；随后在飞书后台核对消息更新权限以及 `card.action.trigger` 是否已加入当前发布版本。

真实验收前请确认：

- 当前发布版本订阅的是新版 `card.action.trigger`，不是旧版 `card.action.trigger_v1`。
- 机器人对目标群可见，且应用拥有发送消息和更新机器人消息所需的当前官方最小权限。
- Webhook 模式的回调地址是正式 HTTPS 地址；长连接模式则不需要填写公网回调地址，但本地进程必须持续在线。
- 不要把 App Secret、Verification Token、Encrypt Key 或事件体中的临时凭证粘贴到群聊、截图或仓库。

## 8. 通讯录范围与负责人解析

- 平台：飞书开放平台 / 管理后台。
- 点击路径：应用 → 权限管理 → 通讯录；管理后台 → 应用可用范围/通讯录范围。
- 权限名称：按邮箱/手机号换 open_id 使用 `contact:user.id:readonly`；读取基础信息使用 `contact:user.base:readonly` 或后台当前提供的等价最小权限，请按官方文档确认。
- 环境变量：无新增前端变量；负责人 open_id 只保存在服务端业务数据中。
- 验证方式：使用测试账号的已保存 open_id、邮箱、手机号分别解析；系统设置“通讯录”从“需检查权限”变为真实探测可用。
- 当前降级：解析失败时工单保留原负责人文本/待分配状态，不阻断创建；错误和日志不回显邮箱、手机号、open_id。
- 是否影响网站：不影响工单主流程；只影响真实人员定向协同。

## 9. 飞书应用审核与可用范围

- 平台：飞书开放平台 / 企业管理后台。
- 点击路径：应用 → 版本管理与发布 → 创建版本 → 提交审核；管理员审批后设置可用范围。
- 权限名称：以上已申请权限的最终审批；不要额外申请“读取群全部消息”等高敏权限，除非业务确有必要。
- 环境变量：不在审批页面或仓库填写任何 Secret。
- 验证方式：使用普通参赛演示账号能打开网页应用、与机器人对话、点击卡片；无权限账号不能访问越权数据。
- 当前降级：本地/浏览器 Mock 演示不依赖审批。
- 是否影响网站：正式飞书租户内可见性受影响；公网网页不受影响。
