# 11 常见问题与排错

## 页面白屏或接口失败

- 确认 `npm run dev` 同时显示前端 5173 与服务端 3001。
- 访问 `/api/health`。如前端单独部署，检查 `VITE_API_BASE_URL`。
- 修改 Vite 环境变量后必须重启；查看浏览器网络请求，不要在截图/日志中暴露 Token。

## 请求 Feishu 但显示 Mock

这是安全降级。打开系统设置查看缺失变量名；服务端不会显示变量值。补齐后重启。若仍降级，确认 `.env` 位于项目根目录且部署平台变量作用于当前环境。

## 飞书免登失败

- 确认在飞书工作台内打开，而非系统浏览器。
- 确认 App ID 与后台应用一致，主页、重定向 URL 和可信域名完全匹配。
- `requestAccess` 错误 103 表示客户端/API 不支持，代码会回退 `requestAuthCode`；仍失败时升级飞书客户端。
- code 一次性且短时有效，不能重复提交。

## 多维表格返回空或 403

应用权限和文档协作者权限必须同时满足；检查高级权限。先运行 `DRY_RUN=true npm run bootstrap:bitable`。不要使用脚本删除/覆盖现有数据。

## 机器人不发消息

确认机器人能力、`im:message:send_as_bot`、机器人入群、可用范围和 chat_id。系统设置的结果会说明是 Mock 预览、发送成功还是可重试失败。业务状态不会因通知失败回滚。

## 工单不能完成

必须先走到“待验证”，填写验证结果和维修后健康度；备件库存不足时会阻止完成。完成接口带幂等键，相同请求不会重复扣库存。

## 如何复位比赛数据

Mock 状态在服务进程内，重启服务即可恢复。Feishu 模式不会自动删除数据；如需重新演示，应使用新的演示多维表格或由管理员人工备份后处理，初始化脚本不会提供破坏性清空。
