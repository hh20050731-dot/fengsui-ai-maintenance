# 烽燧智守 Aily 智能伙伴配置指南

> 当前状态：代码侧工具接口、意图路由与返回结构已准备；Aily 后台创建、知识库绑定和发布需要企业账号人工完成。不要把任何 Secret 粘贴到前端或本文档。

## 1. 创建入口

1. 使用具有企业应用管理权限的账号进入飞书 Aily / 智能伙伴管理后台。
2. 新建企业智能伙伴，名称填写“烽燧智守运维助手”。
3. 系统提示词强调：只基于工具返回和知识引用回答；使用“存在风险、疑似、建议现场确认”等表述；不得宣称真实诊断准确率。
4. 发布前只选择比赛演示范围，正式扩大可见范围需再次人工审批。

## 2. 知识库绑定

- 导入设备说明、检修指南、安全规程和经过审核的维修案例。
- 每个文档保留来源、章节、设备类型、故障类型、风险等级元数据。
- 没有检索结果时明确回答“未找到可引用证据”，不得让模型补写来源。
- 网站同源检索接口：`POST /api/rag/search`。

## 3. API 工具

以下均使用部署后的 HTTPS 域名，返回统一 `{ success, data }` 结构：

| 工具 | 方法与路径 | 输入 | 用途 |
|---|---|---|---|
| 查询设备 | `GET /api/equipment/:id` | `id` | 当前状态和健康度 |
| 查询趋势 | `GET /api/equipment/:id/telemetry?range=24h` | `id` | 遥测趋势 |
| 查询预警 | `GET /api/alerts?deviceId=...` | `deviceId` | 活动预警 |
| 查询工单 | `GET /api/work-orders` | 可选状态 | 当前工单 |
| 查询备件 | `GET /api/spare-parts` | 可选筛选 | 库存校验 |
| 检索知识 | `POST /api/rag/search` | `query/deviceType/faultType/riskLevel/limit` | 引用证据 |
| 运行Agent | `POST /api/agent/run` | `deviceId/task/maxSteps/confirmCreateWorkOrder` | 受控工具编排 |

敏感写操作必须经过网站现有身份、幂等和人工确认逻辑；Aily 不得直接绕过状态机写多维表格。

## 4. 示例问法

- 当前风险最高的设备是什么？
- 1号引风机当前状态如何？
- 为什么判断1号引风机存在轴承温升风险？请给出引用。
- 当前有哪些待处理工单？
- 当前轴承和润滑油库存是否满足检修？

## 5. 验证

1. 连续提问上述问题，确认结果随意图变化。
2. 检查引用编号、标题、章节和来源是否真实存在。
3. 触发无匹配问题，确认没有虚构引用。
4. Agent 创建工单前应显示人工确认；未确认时不得写飞书。
5. Aily 的实际创建、权限名称和发布路径请以当前飞书官方后台显示为准。
