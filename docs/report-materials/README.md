# 团队附加报告素材包索引

| 推荐顺序 | 文件                           | 内容说明                                 | 可直接用于报告           | 需要人工补充                 |
| -------: | ------------------------------ | ---------------------------------------- | ------------------------ | ---------------------------- |
|        1 | `00-项目状态与版本信息.md`     | 分支、HEAD、依赖、测试与构建状态         | 可作为技术证明附录       | 最终提交前可重新核验版本     |

|        3 | `01-项目事实清单.md`           | 30项能力的状态、证据、表述和边界         | 可作为撰写事实底稿       | 飞书后台当前配置可人工复核   |
