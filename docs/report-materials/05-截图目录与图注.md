## 人工截图操作与遮盖要求

### 12-飞书机器人查询结果.png

1. 在已加入机器人的测试群中发送“查询1号引风机状态”。
2. 截取用户问题和机器人完整回答，保留群聊时间与机器人名称。
3. 遮盖无关群成员头像、真实个人手机号、企业敏感群名；不要打开机器人配置或密钥页面。
4. 图注中注明设备监测和研判内容为模拟数据。

### 13-飞书多维表格工单状态.png

1. 打开维修工单表，仅显示工单编号、设备名称、设备编号、故障部位、故障类型、风险等级、工单状态和创建时间。
2. 选择一条已由网页创建并完成状态更新的测试工单。
3. 遮盖多维表格App Token、URL参数、无关人员姓名、其他业务表数据和浏览器账户信息。
4. 不展示任何App Secret、tenant_access_token、Verification Token或Encrypt Key。

### 14-飞书长连接ready日志.png

1. 在本地终端执行 `npm run feishu:ws`。
2. 只截取 `[Feishu WS] connecting`、`[Feishu WS] ready` 和必要的事件类型/处理结果行。
3. 裁掉命令历史、绝对用户名路径、环境变量、消息全文、卡片value和任何令牌。
4. 若日志未出现ready，不得使用旧截图假装当前已连接。
