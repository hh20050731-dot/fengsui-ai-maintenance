# 数据边界与真实性声明

## A. 模拟演示部分

以下内容由固定种子Mock数据、前端故障场景或规则模型生成：

- 12台设备的监测数据与历史趋势；
- 振动、温度、电流、压力和转速；
- 健康度、风险等级和指标贡献度；
- 故障发展过程与维修后的恢复趋势；
- 1号引风机的二级预警和3D故障场景；
- 规则型故障研判、规则匹配度、故障概率场景参数；
- 默认设备、预警、备件库存、知识库和运维日报统计。

这些数据明确标注为“模拟演示数据”，不代表真实垃圾焚烧发电厂设备状态。

## B. 真实联调部分

根据当前代码、测试和项目已有联调记录，以下能力具备真实飞书连接实现：

- 企业自建飞书应用与服务端OpenAPI适配；
- 本地Node进程通过官方SDK建立WebSocket长连接；
- 飞书机器人接收文本消息并回复；
- 飞书多维表格维修工单创建、读取与状态更新；
- 新版卡片事件接收及“确认接单”等状态机调用；
- 网页工单与飞书工单标识映射、`recordId`优先更新；
- Webhook challenge、Token校验和加密回调备用入口。

真实联调指“接口和数据交互可工作”，不表示系统已接入真实电厂生产数据或完成生产部署。

## C. 尚未完成或需要真实项目验证

- DCS、PLC、SCADA、边缘网关或真实传感器接入；
- 基于真实历史故障样本的模型训练和生产准确率评估；
- 剩余寿命预测、故障概率校准和误报/漏报统计；
- 多实例高可用长连接、正式数据库和大规模工业部署；
- 真实经济效益、故障率降低比例、停机时间减少比例；
- 真实电厂长期运行、网络安全、等保、审计和现场验收；
- 与企业ERP/EAM、采购、排班、安全票证和控制系统的正式集成。

## 可直接放入报告的真实性声明

> “烽燧智守”当前为飞书AI创新比赛原型。系统中的设备监测数据、健康度、风险等级、故障发展、维修恢复趋势、规则匹配度及三维故障场景均由模拟数据和可解释规则生成，仅用于展示技术路线和业务闭环，不代表真实设备诊断结果。项目已实现飞书机器人长连接、多维表格维修工单读写及工单状态同步等真实协同能力，但尚未接入真实电厂DCS/PLC与传感器数据，也未形成可对外声明的生产准确率、经济效益或长期运行结论。实际应用必须结合设备说明书、企业安全规程、现场检测和专业人员判断。

## 禁止使用的表述

- “已接入真实垃圾焚烧厂全部生产数据”；
- “模型准确率达到XX%”；
- “已降低XX%故障率或停机损失”；
- “已完成工业级大规模部署”；
- “设备已经损坏”“一定是轴承故障”“系统决定必须停机”。

建议统一使用“存在……风险”“疑似……”“可能与……有关”“建议结合现场检查进一步确认”“是否停机由现场负责人结合安全规程决定”。
