# 02 本地运行指南

## 准备

安装 Node.js 20+，在项目根目录执行：

```bash
npm install
copy .env.example .env
npm run dev
```

Windows PowerShell 也可用 `Copy-Item .env.example .env`。访问 `http://localhost:5173`；接口健康检查为 `http://localhost:3001/api/health`。

## Mock 模式

`.env` 保持：

```dotenv
APP_MODE=mock
VITE_APP_MODE=mock
```

无需 App ID、Secret、多维表格或机器人配置。普通浏览器使用“黄浩 / 项目演示员”。状态保存在服务进程内；重启服务会恢复初始演示数据，便于重复路演。

## Feishu 模式

将 `APP_MODE=feishu` 并按 `.env.example` 补齐变量。Vite 只在启动时读取环境变量，修改后须重启开发服务。配置不完整时服务端控制台只打印缺失变量名并自动降级，系统设置页会显示集成状态。

## 校验命令

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run test:e2e
```

首次执行端到端测试如缺少 Chromium，可执行 `npx playwright install chromium`。此步骤不需要飞书凭证。

## 普通 Node 生产运行

```bash
npm run build
$env:NODE_ENV="production"
npm run start -w @fengsui/server
```

Node 服务同时提供编译后的网页和 `/api`。建议在 Nginx/Caddy 后配置 HTTPS、请求大小、超时和访问日志脱敏。
