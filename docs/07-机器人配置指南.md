# 07 机器人配置指南

## 开启与授权

1. 在应用能力中开启“机器人”。
2. 申请并审核 `im:message:send_as_bot`（以应用身份发消息）。
3. 把机器人加入目标群，或确认应用可向目标用户发消息。
4. 获取目标 `chat_id`，写入服务端 `FEISHU_NOTIFICATION_CHAT_ID`。代码不硬编码任何群/用户 ID。

## 消息行为

- Mock：返回交互卡片 JSON 并在系统设置显示预览，不发送真实消息。
- Feishu：服务端调用 `POST /im/v1/messages?receive_id_type=chat_id`，发送 `interactive` 卡片。
- 卡片包含设备、工况、健康度、风险、异常指标、疑似原因、时限和“模拟演示数据”。
- 发送失败只返回可重试结果并记录错误说明，不回滚预警/工单等业务写入。

## 回调

事件 URL：`https://你的域名/api/feishu/events`。

接口支持 URL challenge、Verification Token 来源校验、event_id/内容摘要幂等，并处理“确认预警”“生成工单”卡片动作。若后台启用 Encrypt Key 加密，当前比赛原型不在本地自行猜测解密协议；应按发布时最新官方 SDK 增加加密中间件后再启用。`FEISHU_ENCRYPT_KEY` 已预留。

卡片 URL 按 `APP_BASE_URL` 生成。确保该域名为 HTTPS、已配置 H5 可信域名并可从飞书客户端访问。比赛原型会把卡片动作记录为“飞书卡片操作人”；生产化必须结合回调中的 operator 标识、组织角色和数据权限做细粒度授权。

## 测试

系统设置 → 发送测试消息。Mock 显示预览；Feishu 模式发送到配置会话。失败时检查机器人是否入群、应用可用范围、权限审核、会话 ID 和 tenant token。
