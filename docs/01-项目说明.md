# 01 项目说明

## 定位

烽燧是一套面向垃圾焚烧发电厂旋转设备与关键辅机的智能运维比赛原型。它把监测、工况基准、健康度、预警、规则诊断、飞书通知、维修工单、备件和知识沉淀组织为一条可演示闭环。

## 业务闭环

监测数据进入 → 工况识别 → 健康度计算 → 异常预警 → AI 辅助分析 → 飞书消息通知 → 创建维修工单 → 维修人员处理 → 备件库存扣减 → 维修效果验证 → 更新设备状态 → 沉淀故障案例。

## 架构边界

- 页面只调用统一 API，不直接调用飞书 OpenAPI。
- `DataRepository` 隔离 Mock 与飞书多维表格。
- `AuthProvider` 隔离演示身份与飞书免登。
- `NotificationProvider` 隔离卡片预览与机器人发送。
- `AiDiagnosisProvider` 默认使用可解释规则模型，并预留真实大模型接口。
- App Secret 与令牌永远不进入前端构建。

## 数据真实性

所有页面固定显示“当前为模拟演示数据，不代表真实设备诊断结果”。规则诊断不使用“已经损坏”“一定是”“必须停机”等绝对表达。项目没有宣称接入真实工厂、取得真实准确率或已生产部署。

## 重点案例

1号引风机 `IDF-001` 在高负荷稳定运行下，6 小时振动由 4.2 上升至 6.8 mm/s、温度由 72 上升至 86℃，健康度为 68。演示维修后振动降至 3.1 mm/s、温度降至 68℃、健康度恢复到 92；该变化由后端状态和持久化适配层驱动。
