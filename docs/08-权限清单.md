# 08 权限清单

坚持最小权限。以下标识已由可访问的飞书官方资料核对；后台中文名可能调整，发布前仍需在当前官方文档确认。

| 权限标识 | 目的 | 必要性 |
|---|---|---|
| `bitable:app` | 查看、编辑和管理项目多维表格 | Feishu 数据模式必需 |
| `im:message:send_as_bot` | 应用机器人发送预警/测试消息 | 机器人必需 |
| `contact:user.employee_id:readonly` | 需要员工 User ID 时读取用户标识 | 可选；只用 open_id 可不申请 |

免登 `requestAccess` 使用空 `scopeList` 获取基础登录信息；服务端“获取用户信息”接口本身不要求通用 scope，手机号、邮箱、受雇信息等敏感字段需要额外字段权限，本项目不读取这些字段。

若订阅群聊消息、卡片回调或新增通讯录能力，请根据当前官方文档逐项申请；不要仅因“可能用到”申请大范围通讯录或消息读取权限。无法确认名称的权限必须在上线审批前由管理员在官方权限搜索中确认，本仓库不会猜测未验证标识。

## 数据权限

API 权限不等于文档权限。多维表格仍需把应用设为协作者，并在高级权限中授予目标数据表/字段访问范围。生产环境建议为应用单独建立数据底座，不授予无关云文档访问权。
