## E2E 隔离

`scripts/run-e2e-server.ts` 强制调用 `createApp({ forceMock: true })`。Playwright 禁止复用外部开发服务，避免本机 `APP_MODE=feishu` 时自动化测试触碰真实多维表格。端到端流程验证：

1. 1号引风机 68 分预警；
2. 生成工单；
3. 待接单 → 已接单 → 检修中 → 待验证 → 已完成；
4. 健康度恢复 92；
5. 风机轴承库存 6 → 5；
6. 关联预警关闭；
7. 知识候选生成；
8. 刷新后状态保留；
9. 重置后恢复初始状态；
10. 3D故障场景与URL联动。
